# Hackathon Ideas

## Idea Backlog

### Agent Wallet Permission Simulator

- User: builders designing agent-controlled wallet flows
- Problem: it is hard to explain what an agent can and cannot do with a wallet permission
- Prototype: a small UI or script that models permission scope, spending limits, expiry, revoke flow, and audit log
- Handbook links: Agent Wallet, Account Abstraction, Agent Workflow, AI Security

### Chain-aware Research Assistant

- User: analysts or builders reviewing protocol activity
- Problem: AI summaries become risky when they ignore current chain state or source reliability
- Prototype: an assistant that combines user question, cited docs, chain data, and a confidence/risk section
- Handbook links: Chain-aware Context, RAG, Web3 Tool Use, Evaluation

### AI Security Checklist For Web3 Agents

- User: project teams preparing agent demos
- Problem: demo agents often skip prompt injection, tool permission, and secret handling risks
- Prototype: a checklist generator that maps an agent workflow to security review items
- Handbook links: AI Security, Agent Workflow, Web3 Tool Use, Wallet

## Selection Criteria

- Can be demoed in a few minutes
- Has a clear user and risk boundary
- Produces visible proof-of-work
- Does not require real funds or sensitive credentials
