# Learning Plan

## North Star

Build enough shared language and practical proof-of-work to design, prototype, and explain an AI x Web3 application with clear boundaries around permissions, security, user control, and verifiable records.

## Week 1: Orientation and Setup

Focus:

- Understand the Handbook structure.
- Set up this public learning repository.
- Start a daily note rhythm.
- Identify the first AI x Web3 prototype direction.

Reading map:

- Handbook overview: https://aiweb3.school/zh/handbook/
- AI basics: LLM, Prompt, Context, RAG, Agent
- Web3 basics: Network, Cryptography, Wallet, Smart Contract, Account Abstraction
- Bridge topics: Chain-aware Context, Web3 Tool Use, Agent Workflow, Agent Wallet, AI Security

Outputs:

- `daily/YYYY-MM-DD.md` daily notes
- At least one `tasks/` proof-of-work note
- At least one `handbook-feedback/` candidate or observation
- A short Hackathon idea list in `hackathon/ideas.md`

## Week 2: AI Basics and Agent Workflow

Focus:

- Prompt boundaries, context design, RAG, tool calling, evaluation
- Human-in-the-loop workflow design

Outputs:

- One small agent workflow sketch
- One evaluation checklist
- One experiment note

## Week 3: Web3 Tooling and Wallet Permissions

Focus:

- Wallets, signatures, smart contracts, RPC tools, account abstraction
- Permission limits, revoke flows, simulation, audit logs

Outputs:

- Web3 tool-use experiment
- Wallet permission notes
- Risk checklist

## Week 4: Hackathon Prototype Preparation

Focus:

- Pick one problem
- Define user, workflow, security boundary, and demo path
- Build or scope a small prototype

Outputs:

- Hackathon project brief
- Demo script
- Submission checklist

## Daily Loop

1. Check WCB Learning page for current course/task context.
2. Read the relevant Handbook section.
3. Record the smallest useful learning output.
4. Write a check-in draft.
5. Save blockers as questions or feedback items.
6. Review before committing.
