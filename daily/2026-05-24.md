## Learned

- Week 1 is not only about reading concepts; it asks for visible proof-of-work: repo records, concept cards, tool setup notes, agent logs, and small experiments.
- A Learning Agent is most useful when it helps maintain a repeatable workflow: read task, break down requirements, draft artifacts, review risk, record proof, and prepare submission links.
- AI can draft plans, notes, diagrams, and small demos, but wallet actions, signatures, transactions, and public submissions still need human confirmation.
- For Web3 learning, the safe path is to start with a test-only wallet, testnet funds, block explorer verification, and clear records of transaction hashes instead of screenshots containing sensitive details.
