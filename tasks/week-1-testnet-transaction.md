## What I Learned

- A testnet transaction still follows the same basic flow as a mainnet transaction: wallet confirmation, broadcast, block inclusion, transaction hash, and block explorer verification.
- The transaction hash is the main public proof that the transaction happened.
- A block explorer can verify status, block number, sender, receiver, value, gas used, transaction fee, and timestamp.
- Gas is paid for execution even on a testnet, but SepoliaETH has no real-world value.
- Wallet confirmations should always be reviewed carefully before signing or sending.
