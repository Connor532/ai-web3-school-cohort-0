# Week 1 Web3 Practice Plan

## Goal

Prepare the exact safe path for the Web3 hands-on tasks that require a wallet.

## Human-only Setup

1. Install a browser wallet plugin such as MetaMask.
2. Create a dedicated test-only wallet.
3. Write the seed phrase offline and never put it in GitHub, screenshots, chat, or AI tools.
4. Switch to the Sepolia testnet or the network specified by the course.
5. Get test ETH from a trusted faucet.

## Human Confirmation Rules

- Do not give the seed phrase or private key to an AI tool.
- Review every wallet prompt before signing.
- Use testnet funds only.
- Cancel any prompt that contains unexpected contract, network, amount, or permission details.
- Record public hashes and links only after execution.
