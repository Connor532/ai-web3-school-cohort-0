## Goal

Set up a public learning workspace and define a repeatable learning loop for AI x Web3 School.

## Requirements

- Public GitHub repository
- README with program context, links, privacy reminder, and structure
- Learning plan or Week 1 goals
- Core directories for daily notes, tasks, experiments, Handbook feedback, and Hackathon preparation
